# Music-Recommendation-System
A web-based application that helps users discover and manage music easily. The system allows users to search songs, play music, create playlists, rate songs, and receive song suggestions based on their preferences and listening activity.  This project is designed as a simple and user-friendly platform for organizing and exploring music.  
🚀 Features

🔐 User Registration and Login

🔎 Search songs by title, artist, album, or genre

▶️ Play music tracks

🎶 Create and manage playlists

⭐ Rate songs and provide feedback
